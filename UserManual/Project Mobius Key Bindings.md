# Project Mobius Input Action Bindings and Combos

# Desktop and Mac Bindings

## **1\. Camera & Movement Controls**

| Action | 🪟 Windows Input | 🍎 Mac Input |
| :---- | :---- | :---- |
| **Move Camera** *(Forward, Backward, Left, Right)* | **\[ W \] \[ A \] \[ S \] \[ D \]** *(Hold)* ⚡ **Speed Up (5x): \[ Shift \]** \+ **\[ W/A/S/D \]** | **\[ W \] \[ A \] \[ S \] \[ D \]** *(Hold)* ⚡ **Speed Up (5x): \[ Shift ⇧ \]** \+ **\[ W/A/S/D \]** |
| **Zoom Camera** *(In / Out)* | **\[ Scroll Up \]** / **\[ Down \]** | **\[ Scroll Up \]** / **\[ Down \]** |
| **Rotate Camera** *(Keyboard Orbit)* | **\[ Q \]** / **\[ E \]** *(Hold)* ⚡ **Speed Up (5x): \[ Shift \]** \+ **\[ Q \]** / **\[ E \]** | **\[ Q \]** / **\[ E \]** *(Hold)* ⚡ **Speed Up (5x): \[ Shift ⇧ \]** \+ **\[ Q \]** / **\[ E \]** |
| **Pivot Camera** | **\[ RMB \]** \+ **\[ Q \]** / **\[ E \]** | **\[ RMB \]** \+ **\[ Q \]** / **\[ E \]** |
| **Pan View** | **\[ MMB \]** \+ **\[ Move Mouse \]** | **\[ MMB \]** \+ **\[ Move Mouse \]** |
| **Orbit View** | **\[ RMB \]** \+ **\[ Move Mouse \]** | **\[ RMB \]** \+ **\[ Move Mouse \]** |
| **Reset Camera** | **\[ Ctrl \]** \+ **\[ R \]** | **\[ Control \]** \+ **\[ R \]** |

### **⚡ Quick Tips**

* **Speed Modifier:** Hold **\[ Shift \]** (Windows) or **\[ Shift ⇧ \]** (Mac) while moving, rotating, or time-stepping to increase the speed by **5x**.
