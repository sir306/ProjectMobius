# Controls

This page keeps the commonly used desktop controls in one place. For the
full project reference, also see
[BuildDocs/Project Mobius Key Bindings.md](../UnrealFolder/ProjectMobius/BuildDocs/Project%20Mobius%20Key%20Bindings.md).

## Camera and Movement

| Action | Windows | Mac |
|--------|---------|-----|
| Move camera | `W` `A` `S` `D` | `W` `A` `S` `D` |
| Speed modifier | `Shift` + movement keys | `Shift` + movement keys |
| Zoom camera | Scroll wheel | Scroll wheel |
| Rotate camera | `Q` / `E` | `Q` / `E` |
| Pivot camera | `RMB` + `Q` / `E` | `RMB` + `Q` / `E` |
| Pan view | `MMB` + mouse move | `MMB` + mouse move |
| Orbit view | `RMB` + mouse move | `RMB` + mouse move |
| Reset camera | `Ctrl + R` | `Control + R` |

## Simulation and Analysis

| Action | Windows | Mac |
|--------|---------|-----|
| Start / pause simulation | `Spacebar` | `Spacebar` |
| Step time backward / forward | `Left Arrow` / `Right Arrow` | `Left Arrow` / `Right Arrow` |
| Faster stepping | `Shift` + arrow keys | `Shift` + arrow keys |
| Rotate sun | `Ctrl + Left Arrow` / `Ctrl + Right Arrow` | `Control + Left Arrow` / `Control + Right Arrow` |
| Inspect pedestrian metrics | `Ctrl + Hover` | `Control + Hover` |
| Select pedestrian | `Ctrl + LMB` | `Control + LMB` |
| Pin pedestrian metrics | `Ctrl + RMB` or double click | `Control + RMB` or double click |

## System

| Action | Windows | Mac |
|--------|---------|-----|
| Screenshot | `Ctrl + C` | `Control + C` |
| Quit application | `Esc` | `Esc` |
